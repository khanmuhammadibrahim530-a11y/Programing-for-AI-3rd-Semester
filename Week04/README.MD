# Week 4: Object-Oriented Programming and File Handling

BS Artificial Intelligence - Programming for AI (Lab 4)

## Project Description
This repository contains the completed tasks for Week 4 Laboratory Manual.

## File Hierarchy
- `student.py`: Student class with attribute encapsulation and grade validation.
- `experiment.py`: Reusable Experiment class for AI experiment metrics.
- `01_inheritance.py`: Model inheritance demonstrating parent and subclass behavior.
- `02_student_storage.py`: CSV reading and student report file generation.
- `03_experiments.py`: Saving and loading AI experiment records using JSON.
- `04_debugging.py`: Fixes for common OOP and file handling syntax/runtime errors.
- `05_experiment_tracker.py`: Mini-project for tracking AI model performance with assertions.
- `data/students.csv`: Sample input dataset of student marks.
- `reports/`: Text reports generated for students and experiment summaries.
